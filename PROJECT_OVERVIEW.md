# ReviewQuest: The Gamified Study RPG

## Project Vision
**ReviewQuest** is a gamified learning platform that transforms dense study materials into an immersive Sci-Fi RPG experience. By leveraging AI to process user-uploaded documents (like PDFs), the application generates challenging multi-level "Dungeons" where knowledge is the primary weapon.

---

## Core Features & Current Progress

### 1. AI-Powered Knowledge Extraction
- **PDF Processing:** Automated text extraction from uploaded study materials using `pdf-parse`.
- **Dynamic Dungeon Generation:** Integration with OpenAI to process uploaded materials into structured JSON representing a multi-level dungeon. Each "Floor" or "Level" corresponds to a distinct sub-topic extracted from the document.
- **Question Types:** Generates three types of challenges (Multiple Choice, True/False, Enumeration) based on user selection. Strict Zod schemas ensure consistent AI responses.

### 2. Tactical RPG Combat Engine
- **Multi-Level Progression:** Dungeons are split into floors. Clearing a floor triggers a visual descent to the next level, fighting a sequence of thematic enemies.
- **Battle Mechanics:** Players engage in turn-based combat against AI "Bosses" (e.g., The Academic Overlord).
- **Damage System:** 
  - **Attack:** Correct answers deal damage to enemies.
  - **Defense:** Incorrect answers result in health loss for the player, mitigated by defense stats.
- **Combo & Ultimate:** Successive correct answers build a combo meter, increasing damage and charging a powerful "Ultimate" ability.

### 3. Character Progression & Customization
- **Modular Character Creator:** Customize gender, skin tone, hair style, and modular facial features (optics, mouth, etc.).
- **Dynamic Sprite Rendering:** The `CharacterPreview` engine dynamically composites sprites, correctly applying gender-specific fitted armor sprites (e.g., `male-2.png`, `female-2.png`) while keeping generic high-res icons (e.g., `sentinel_armor.png`) for UI elements like The Forge.
- **Leveling System:** Earn XP through study sessions to level up and gain skill points to upgrade Attack and Defense.
- **The Forge (Crafting):** 
  - Collect loot fragments from victories.
  - **High-Fidelity Visual Previews:** Real-time rendering of high-quality item assets (e.g., Sentinel Plating) during the compilation process.
  - Craft advanced weapons and armor to improve system stability and output.

### 4. Exploration & Review
- **Mission Briefing/Debriefing:** Thematic UI framing the start and end of a dungeon run, now displaying the multi-level structure and overall title generated by the AI.
- **Intel Log:** A detailed review system that tracks "mistakes" (wrong answers), providing rationales and correct answers for post-battle analysis.

---

## Technical Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS & Framer Motion (for high-fidelity animations)
- **State Management:** Zustand (with persistence and multi-level progression tracking)
- **Backend/Database:** Supabase
- **AI Integration:** OpenAI SDKs with strict JSON Schema Validation (Zod)
- **Icons:** Lucide-React
