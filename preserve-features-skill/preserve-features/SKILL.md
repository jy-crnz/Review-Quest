# Preserve Features Mandate

When updating, modifying, or refactoring code, you MUST preserve all existing features, logic, and functionalities unless explicitly instructed by the user to remove them.

Do not delete or omit existing code during updates. Ensure that all prior features continue to work exactly as they did before any modifications are made. If you are uncertain whether a piece of code is a feature or a bug, assume it is a feature and preserve it.
